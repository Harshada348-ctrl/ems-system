# Employee Management System

A full-stack Employee Management System built using React and Spring Boot.

## Technologies
- React
- Spring Boot
- Java
- MySQL
- JWT Authentication
- Axios
- Bootstrap

## Features
- User registration and login
- JWT authentication
- Add employees
- View employees
- Update employees
- Delete employees

## Project Structure
- fullstack/ems-frontend → React frontend
- ems backend/ems-backend → Spring Boot backend

## How to Run

### Frontend
cd fullstack/ems-frontend
npm install
npm run dev

### Backend
Open the backend project in IntelliJ IDEA and run the Spring Boot application.
